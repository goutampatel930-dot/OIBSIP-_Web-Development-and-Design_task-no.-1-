# 🚀 CodeMaster - EdTech Landing Page

A modern and responsive landing page for an EdTech business that teaches coding.

This project is built using only **HTML and CSS**.  
It focuses on clean layout, proper spacing, alignment, color palette, and non-overlapping design.


## 📌 Project Overview

CodeMaster is a fictional online coding platform that offers:

- Beginner-friendly courses
- Live project-based learning
- Career support
- Full stack development training

This landing page is designed to look professional and modern while maintaining clean structure.


## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox for layout)
- Google Fonts (optional if added)
- Unsplash (for coding image)

## 🚀 How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Double click `index.html`
4. Open in any browser (Chrome recommended).

No installation required.
